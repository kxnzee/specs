## Why

Участнику, помогающему поддержке разбирать обращение, нужен идентификатор
сборки сервера текущей конференции. Отдельная строка в Conference info позволит
прочитать его без доступа к серверным журналам.

## What Changes

- `jitsi-control` передаёт дополнительное необязательное свойство
  `focus-build-id` через существующий обмен свойствами конференции.
  Источник — существующий идентификатор сборки, уже передаваемый участникам
  как часть версии сервера. Адресная проверка на этапе Design подтвердила
  возможность его использования.
- `lib-jitsi-meet` предоставляет новое свойство через существующий механизм.
  Рабочая логика не меняется; в рамках Change проверяется сохранение контракта.
- `jitsi-web` показывает строку «Focus build id» в Conference info всем
  участникам, включая немодераторов. Отсутствующее, пустое или пробельное значение
  скрывает строку без заглушки и ошибки. Любая другая строка показывается без
  изменения; длинные значения используют существующее представление без
  отдельного обрезания. Эти уточнения подтверждены владельцем на этапе Design
  и отражены в Delta Specs.
- Остальная информация о конференции сохраняет поведение. Старый сервер,
  который не передаёт новое поле, остаётся совместимым.

## Capabilities

### New Capabilities

- `conference/focus-build-id-visibility`: передача идентификатора сборки сервера
  текущей конференции и его условное отображение участникам в Conference info.

### Modified Capabilities

Нет.

## Repository Impact

| Repository | Capabilities |
|---|---|
| `jitsi-control` | `conference/focus-build-id-visibility` |
| `lib-jitsi-meet` | `conference/focus-build-id-visibility` |
| `jitsi-web` | `conference/focus-build-id-visibility` |

## Impact

Затрагиваются серверная публикация свойства, подтверждение существующей передачи
в библиотеке и отображение в веб-интерфейсе. Нового транспорта, хранилища,
журналирования и аналитики не требуется. Изменение не касается
`jitsi-videobridge`, маршрутизации медиа, выбора видеомостов, аутентификации
и правил доступа к конференции.
