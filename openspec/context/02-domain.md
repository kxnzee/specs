# Предметная область

## Термины

| Термин или сокращение | Значение в этом продукте |
|---|---|
| Conference | Видеовстреча, объединяющая участников, сигнализацию и медиапотоки |
| Participant / Endpoint | Участник конференции и его подключение к конференции |
| Visitor | Ограниченный Participant, который получает медиапотоки, но не отправляет собственные аудио и видео |
| Focus | Роль `jitsi-control`: координирует конференцию и соединения участников |
| JVB | `jitsi-videobridge` — компонент, принимающий и пересылающий медиапотоки между участниками |
| MUC | Комната конференции в XMPP, объединяющая участников и управляющие компоненты |
| External API | Публичный контракт для встраивания Jitsi Meet в сторонний продукт |
| Relay / Octo | Межмостовое соединение для конференций, распределённых между несколькими JVB |

## Связи понятий

- Conference объединяет участников и связанные с ней сигнальные и медиасессии;
  одну Conference может обслуживать несколько совместимых Bridge (JVB).
- External application встраивает Conference через публичный External API.
- Участник может присоединиться к Conference, участвовать в ней и покинуть её.
- Conference может получить Bridge, расшириться на дополнительные совместимые
  Bridge и завершиться.
